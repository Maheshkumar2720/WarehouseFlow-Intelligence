# WarehouseFlow Intelligence — Synthetic Dataset v1
Fictional TechCare Logistics device-repair/returns warehouse.
Synthetic portfolio data only; no employer/customer/proprietary data.

Period: 2025-10-01 to 2026-09-30
10,000 SKUs | 28,000 storage locations | 50,000 requests | ~75,000 movement lines | 180,000 inventory observations

Core analysis: movement workload, completion/backlog, processing time, location utilisation,
SKU fragmentation, movement routes, exceptions, forecasting and AI-assisted operational insight.
Synthetic capacities/values are assumptions and must not be presented as actual company figures.
